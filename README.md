# Skill: Mapa do edital

Organiza o conteúdo programático de um edital em pontos, com o tamanho de cada um, as normas citadas e o tipo de estudo sugerido.

Skill da imersão **IA para concursos**, do PRO Grupo. Uma skill é uma instrução fixa que a IA segue sempre do mesmo jeito: você escreve uma vez e usa sempre.

## Como usar

1. Abra uma conversa nova na sua IA de chat, ou crie um projeto.
2. Cole o texto de [SKILL.md](SKILL.md) como primeira mensagem (ou como instrução do projeto).
3. Na mensagem seguinte, entregue o material: o conteúdo programático do seu cargo, colado do edital. A incidência sempre começa como "Sem dado": a skill não diz o que mais cai.
